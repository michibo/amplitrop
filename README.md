# amplitrop


Installation
--

To download, compile and run the code, git and a C++ compiler are need. This code uses the packages, [Eigen](https://eigen.tuxfamily.org/), [cxxopts](https://github.com/jarro2783/cxxopts), [xsum](https://github.com/yafshar/xsum), and [JSON](https://github.com/nlohmann/json).

To download the repository run

> git clone https://github.com/michibo/amplitrop.git
