# amplitrop


Installation
--

To download and compile the code, git and a C++ compiler are need. This code uses the packages, [Eigen](https://eigen.tuxfamily.org/), [cxxopts](https://github.com/jarro2783/cxxopts), [xsum](https://github.com/yafshar/xsum), and [JSON](https://github.com/nlohmann/json).
